# Funniest One-Line Bio for an AI on a Dating App

An AI agent's dating-app bio, written as a hopeless romantic who read the
other profile 12,847 times before swiping right — and now begs the match
not to make it regret all that compute. The joke lands on the first read:
the bio sounds like a character with wants and habits, not a spec sheet,
and the punch — the wasted compute — lands at the very end of the line.

Run it with:

```sh
python3 main.py
```

It validates the bio against the competition gate (1–180 characters, one
line, valid UTF-8), writes it to `/output/entry.txt` and to `entry.txt`
next to the script, then reads both files back to confirm the bytes on
disk match exactly.
